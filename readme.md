pertemuan 3  USE CASE DIAGRAM DAN USE CASE DESCRIPTION 

1. Menuliskan batas sistem, aktor, kebutuhan, aturan bisnis, dan asumsi dari 
skenario yang diberikan. 
2. Menentukan use case berdasarkan tujuan aktor, bukan berdasarkan 
nama tombol, tabel, atau langkah teknis. 
3. Membuat use case diagram yang konsisten dengan daftar kebutuhan dan 
hubungan aktor–fungsi. 
4. Menyusun dua use case description yang memuat pemicu, prasyarat, alur 
utama, alur alternatif atau pengecualian, dan pascakondisi. 
5. Menunjukkan keterlacakan setiap use case ke kebutuhan yang 
mendasarinya. 
6. Memperbaiki model berdasarkan review dan mendokumentasikan 
perubahan pada versi berikutnya.
